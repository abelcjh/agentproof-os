# Proposal intro draft

AgentProof OS is an open-source Agent Infra control plane for enterprise multi-agent teams. It converts risky workflows such as refunds, claims, compliance review, or ops remediation into verifiable execution receipts: role-based task decomposition, reusable Skills, MCP-style tools, deterministic result verification, security audit, human approval boundary, and tamper-evident evidence capture. The first runnable fixture shows six agents processing a financial-risk refund case and blocking unsafe execution until approval is present.

## Chinese-length compact draft

AgentProof OS 是面向企业多智能体协作的开源控制层，把退款、理赔、合规审查等高风险流程转化为可验证执行凭证：多角色任务拆解、可复用 Skills、MCP 工具接口、确定性校验、安全审计、人类审批边界与哈希证据链。首个场景演示 6 个 Agent 处理退款风险并在缺少审批时自动阻断执行。
